# Restock Landing Page

`restock-landing-page` is the business static page for the Restock inventory management platform that displays information about the product and its features.

This website servers to build trust and credibility with potential customers, showcase the platform's capabilities, show the benefits of the solution and attract new users.

## Purpose

The main purpose of the Landing Page is to provide a centralized website with all the information needed to understand the platform's features and benefits.

In the current version, the website focuses on:

- Information about the product.
- Benefits of the platform.
- Testimonials from potential customers.
- Description of the main features of the platform.
- Video sections about the product and the development team.
- Contact information.
